# Intermediate Results

This folder contains all intermediate experimental outputs.

## File Categories

### LLM Experiments (N=5)
- `llm_generated_prefixes_5.txt` - Raw LLM-generated prefixes
- `llm_prefix_eval_results_5.*` - SAT evaluation results
- `llm_corrected_prefixes_5.*` - UNSAT-core repaired prefixes

### Paper-Guided Experiments (N=5 and N=7)
- `paper_guided_prefixes_*` - Theory-guided prefixes
- `paper_prefix_eval_results_*` - SAT evaluation results
- `paper_corrected_prefixes_*` - Repaired prefixes
- `paper_guided_theory_notes.txt` - Theory rule documentation
